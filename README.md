# Forever Compass

Flèche ou boussole à placer où tu veux sur l'écran, pour **WoW Forever**.

- Vise la quête suivie, un point posé sur la carte, ou `/fc goto 45.2 63.1`.
- Mort : flèche rouge vers ton cadavre.
- Compatible Questie (points « TomTom » envoyés par Questie quand TomTom n'est pas installé).
- Styles de flèche, boussole en bande, couleurs, infos facultatives.

Réglages : Échap > Options > AddOns > Forever Compass, ou `/fc`.

## Installation et mises à jour avec WowUp
1. Installe [WowUp](https://wowup.io) et ajoute ton dossier `_forever_`.
2. *Get Addons* > *Install from URL* > colle l'adresse de ce dépôt.
3. Les nouvelles versions apparaissent ensuite dans WowUp.

## Installation à la main
Télécharge le zip de la dernière [release](../../releases/latest) et décompresse-le dans `_forever_\Interface\AddOns\`.
